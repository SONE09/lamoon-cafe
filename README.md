# ละมุน · Lamoon Coffee

เว็บร้านกาแฟสไตล์มินิมอล โทนครีมและน้ำตาล พร้อมหน้าลูกค้าบนมือถือและหลังร้านที่ใช้ฐานข้อมูลร่วมกัน

## เปิดดูในเครื่อง

ต้องมี Python 3.10 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม ไลบรารีสร้าง QR รวมอยู่ใน `lib/` แล้ว

ดับเบิลคลิก `start.cmd` หรือเปิด Terminal ในโฟลเดอร์นี้แล้วรัน:

```text
python run.py
```

เปิดหน้าร้านที่ http://127.0.0.1:8787 และหลังร้านที่ http://127.0.0.1:8787/admin

เมื่อเปิดครั้งแรก ระบบสร้างบัญชี `admin` และแสดงรหัสผ่านสุ่มในหน้าต่างที่เปิดระบบ ให้เก็บรหัสนี้ไว้ หน้าต่างต้องเปิดค้างระหว่างใช้งาน กด Ctrl+C เพื่อหยุด

ฐานข้อมูลเก็บที่ `data/cafe.db` การเปิดครั้งต่อไปจะใช้ข้อมูลเดิม

## สั่งจากมือถือและรู้เลขโต๊ะ

1. ให้คอมพิวเตอร์ร้านกับมือถืออยู่ใน Wi-Fi เดียวกัน
2. ดับเบิลคลิก `start-mobile.cmd` หรือรัน `python run.py --mobile`
3. เข้าหลังร้าน → ตั้งค่าร้าน → ตรวจที่อยู่เว็บสำหรับ QR ให้ตรงกับที่โปรแกรมแสดง
4. ไปที่ “โต๊ะและบิล” → “QR โต๊ะ” → พิมพ์ป้าย หรือพิมพ์ QR ทุกโต๊ะ
5. ลูกค้าสแกน QR แล้วจะเห็นเลขโต๊ะก่อนเลือกเมนู ออเดอร์ถูกผูกกับโต๊ะจากรหัสใน QR โดยเซิร์ฟเวอร์

หากคอมพิวเตอร์มีหลายเครือข่าย เลือก IP ที่มือถือเข้าถึงได้ด้วย `python run.py --mobile --address 192.168.1.10` ไม่ใช้ที่อยู่ `127.0.0.1` ใน QR สำหรับมือถือ

ถ้าโทรศัพท์เปิดไม่ได้ ให้ตรวจ Wi-Fi และการอนุญาตรับการเชื่อมต่อ Python ในเครือข่ายส่วนตัวของคอมพิวเตอร์ หลังเปลี่ยน IP หรือออก QR ใหม่ ต้องพิมพ์ป้ายใหม่

## ระบบที่มี

- ลูกค้า: หมวดเมนู ค้นหา ตัวเลือกร้อน/เย็น ขนาด ความหวาน นมโอ๊ต เพิ่มช็อต หมายเหตุ ตะกร้า และติดตามสถานะ
- การบริการ: เรียกพนักงาน ขอเช็กบิล และหมายเลขโต๊ะจาก QR
- ออเดอร์: รับ → เตรียม → พร้อมเสิร์ฟ → เสิร์ฟแล้ว ยกเลิกก่อนเตรียมและคืนสต็อก
- เมนู: เพิ่ม/แก้ไขราคา คำอธิบาย หมวด เปิด/ปิดขาย และสูตรวัตถุดิบต่อรายการ
- สต็อก: หักตามสูตรในออเดอร์ เติมวัตถุดิบ ประวัติความเคลื่อนไหว และเตือนใกล้หมด
- โต๊ะ: ชื่อ จำนวนที่นั่ง เปิด/ปิดโต๊ะ และออก QR ใหม่เพื่อยกเลิก QR เดิมเมื่อไม่มีบิลค้าง
- บิล: รวมออเดอร์ของโต๊ะ ส่วนลด บันทึกเงินสด/โอน/บัตร ใบเสร็จ และพิมพ์
- รายงาน: ยอดชำระรายวัน เมนูขายดี ยอดเฉลี่ยต่อบิล และส่งออก CSV ตามช่วงวันที่
- พนักงาน: บัญชีผู้จัดการ แคชเชียร์ บาริสต้า และการกำหนดสิทธิ์
- ตั้งค่าร้าน: ชื่อ คำอธิบาย เวลาเปิดรับออเดอร์ ที่อยู่สำหรับ QR และโหมดตัวอย่าง

โหมดตัวอย่างเริ่มต้นมี 12 โต๊ะ 8 เมนู และออเดอร์สาธิตที่ระบุว่า DEMO ปุ่มเลือกโต๊ะทดลองใช้เพื่อดูการทำงาน เมื่อปิดโหมดตัวอย่าง ลูกค้าต้องใช้ QR เพื่อระบุโต๊ะ

ยอดในรายงานนับจากบิลที่พนักงานยืนยันรับชำระแล้ว ใบรับเงินเป็นใบเสร็จของร้าน ไม่ใช่ใบกำกับภาษี ราคาตัวอย่างเป็นราคาสุทธิ ไม่มีการบวกภาษีหรือค่าบริการเพิ่ม

## สำรองข้อมูล

รัน `python backup.py` ได้ระหว่างระบบเปิดอยู่ ไฟล์สำรองที่สอดคล้องกันจะอยู่ใน `backups/` เก็บไว้แยกจากเครื่องร้าน หากต้องกู้คืน ให้หยุดระบบก่อน เก็บฐานข้อมูลเดิมไว้ แล้วใช้ไฟล์สำรองแทน `data/cafe.db`

## ขอบเขตเวอร์ชันนี้

เป็นตัวอย่างระบบที่ทำงานในเครื่องหรือ Wi-Fi ของร้าน การรับชำระเป็นการบันทึกโดยพนักงาน ต้องตรวจเงินสดหรือรายการธนาคารก่อนกดรับชำระ ยังไม่มีการเชื่อม payment gateway หรือบริการออนไลน์ สำหรับเปิดผ่านอินเทอร์เน็ตต้องจัดโฮสต์ HTTPS และตั้งค่าการใช้งานจริงเพิ่มเติม

ภาพเมนู 3 ภาพสร้างด้วย Imagegen เพื่อใช้ในร้านตัวอย่าง ไลบรารี QR เป็น `qrcode` 8.2 พร้อมใบอนุญาตใน `lib/QRCODE-LICENSE.txt`
